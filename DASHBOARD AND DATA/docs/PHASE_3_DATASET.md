# AeroTwin-4 Phase 3 Dataset Specification

## 1. Directory Structure

Datasets generated by Phase 3 are stored under `data/generated/phase3/`:

```text
data/generated/phase3/
├── healthy/
│   ├── HEALTHY_001_raw.csv
│   └── HEALTHY_001_metadata.json
├── cylinder/
│   ├── CYLINDER_3_SEV040_raw.csv
│   └── CYLINDER_3_SEV040_metadata.json
├── bearing/
│   ├── BEARING_SEV040_raw.csv
│   └── BEARING_SEV040_metadata.json
├── cooling/
│   ├── COOLING_SEV040_raw.csv
│   └── COOLING_SEV040_metadata.json
├── lubrication/
│   ├── LUBRICATION_SEV040_raw.csv
│   └── LUBRICATION_SEV040_metadata.json
└── windows/
    ├── HEALTHY_001_windows.csv
    ├── CYLINDER_3_SEV040_windows.csv
    ├── BEARING_SEV040_windows.csv
    ├── COOLING_SEV040_windows.csv
    └── LUBRICATION_SEV040_windows.csv
```

---

## 2. Sliding Window Configuration

- **Window Size**: 5.0 seconds (500 samples at 100 Hz)
- **Stride**: 1.0 second (100 samples at 100 Hz)
- **Aggregations**: Mean, Std, Min, Max, RMS, Peak per sensor channel.
- **Anti-Leakage Partitioning**: Train / Validation / Test sets are split strictly by **simulation run IDs**, preventing window overlap leakage across splits.
